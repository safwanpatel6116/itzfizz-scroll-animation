# ItzFizz Scroll Animation

A modern, responsive creative studio landing page built with Next.js, JavaScript, GSAP, and ScrollTrigger. This project features animated text, staggered statistics, and scroll-controlled sports car movement.

## Live Demo

[https://itzfizz-scroll-animation-lovat.vercel.app/]

## Features

- Animated hero section with headline fade-in.
- Staggered statistics animations.
- Scroll-controlled car movement using GSAP ScrollTrigger.
- Reversible animations when scrolling up.
- Responsive desktop and mobile layouts.
- Contact section with an email link.

## Tech Stack

- Next.js
- JavaScript
- React
- GSAP
- GSAP ScrollTrigger
- CSS

## Getting Started

### 1. Clone the repository

```bash
git clone [https://github.com/safwanpatel6116/itzfizz-scroll-animation.git]
cd itzfizz-scroll
```


### 2. Install dependencies

```bash
npm install
```

### 3. Start the development server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.


Run the production build locally:

